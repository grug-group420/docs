Documentation for the grug-group420 ecosystem, covering:

- **[grugbot420](https://github.com/grug-group420/grugbot420)** — Neuromorphic cognitive engine (Julia)
- **[Bindboss](https://github.com/grug-group420/Bindboss)** — Self-extracting executable packer (Go)
- **[grug-cli](https://github.com/grug-group420/grug-cli)** — Zero-dep developer toolkit (Bun.js)
- **[grugbot-server](https://github.com/grug-group420/grugbot-server)** — Web server + playground

## Run Locally

```bash
git clone https://github.com/grug-group420/docs.git
cd docs
python3 -m http.server 8000
# Visit http://localhost:8000
```
